Close the game tab before importing.

While the game is running it keeps its own copy of the save in memory and writes it back when it closes — that overwrite can land on top of your import. Close the game tab, count two seconds, then import. Reopen the game afterwards.

How to use this page
  1. Back up: press Download on a row. You get a .sol file — the game's own save format. Keep as many as you like; they don't interfere.
  2. Restore: close the game tab, then press Import on the row you want to overwrite and pick the .sol file. A file can only go back into the save it came from (its name is stored inside it), which prevents mixing characters up.
  3. Row missing (site data cleared, new computer)? Use Import a .sol file… below the list — it takes the name from the file itself. Boot the game once first so the browser has a save slot to write into.
  4. Start over without deleting your backup: download first, then clear this site's data in the browser; the game boots a fresh level-1 character on the next visit.

The game's own Save Manager (the gear icon in-game) can also download and restore saves. Both work; this page is just a single list of all of them.
