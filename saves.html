Characters & saves Straw Hat Samurai: Duels — local solo build. Everything here lives in this browser only.

Close the game tab before importing or switching.

While the game is running it keeps its own copy of the save in memory and writes it back when it closes — that overwrite can land on top of your import. Close the game tab, count two seconds, then import or switch. Reopen the game afterwards, then press Continue.

Saved characters

Characters you switched away from on the game's start menu. Make active puts one back in play — whatever is in play now is filed here in its place, so nothing is lost.

The character in this browser

This is what the game loads right now, stored as two objects that belong together: shsd (the index) and shsd_guest (the character). Download both if you want a full copy — a character without its index will not load.

Restore from a file

Use this when the save is gone from the table above (cleared site data, new computer). The file is put back under the name stored inside it. Boot the game once first so the browser has a save index to write into.

How to use this page
  1. Switch character: press Make active on a saved character. The one you are playing now takes its place in this list, so nothing is lost. Close the game tab first, switch, then reopen the game and press Continue.
  2. Back up: press Download on any row. You get a .sol file — the game's own save format. Keep as many as you like; they don't interfere.
  3. Restore: close the game tab, then press Import on the row you want to overwrite and pick the .sol file. A file can only go back into the save it came from (its name is stored inside it), which prevents mixing characters up.
  4. Row missing (site data cleared, new computer)? Use Import a .sol file… above — it takes the name from the file itself.
  5. Forget: deletes a saved character from this browser for good. Press Download first if you want a file to keep.
  6. Start over without deleting your backup: download first, then clear this site's data in the browser; the game boots a fresh level-1 character on the next visit.

The game's own Save Manager (right-click in the game) can also download and restore saves. Both work; this page is just one list of all of them.
